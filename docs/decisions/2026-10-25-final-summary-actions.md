# Bilan final : actions simplifiées

Le bilan final propose une action principale d'enregistrement du PNG, puis les actions secondaires disponibles sur la plateforme.

- Sur desktop : enregistrer, ouvrir le dossier, retourner au lobby.
- Sur le Web : enregistrer, retourner au lobby.
- Le partage système direct et sa copie de texte de secours sont supprimés.
- Le téléchargement Web conserve `JavaScriptBridge.download_buffer`.

Les boutons sont regroupés dans une colonne centrée. Masquer une action retire automatiquement son emplacement grâce au conteneur.
